# nonebot_plugin_qq_daily_report —— qqbot 分支

群聊日报插件 · **QQ 官方机器人版**（OneBot v11 版在 [`nonebot` 分支](https://github.com/zlqd123/nonebot_plugin_qq_group_daily_analysis/tree/nonebot)）。

- 海报 + 漫画日报：漫画为「分镜 + 生图（火山方舟 Seedream）」，涉敏自动脱敏改写重试
- 指令：`群日报` / `群日报漫画` / `群日报整体`，支持每群独立定时推送（默认附带漫画）
- 部署：把 `nonebot_plugin_qq_daily_report/` 放进 NoneBot 的 `extra_plugins/`，
  按 [插件 README](./nonebot_plugin_qq_daily_report/README.md) 配置 `GDRQ_` 前缀项

当前与 bison2 线上部署一致。
